# Lotomania Estrutura Livre V1

Projeto Android independente.

## Como funciona
1. Escolha o TXT/CSV de resultados.
2. Informe concurso inicial e final.
3. Clique em "Montar campos de pontuação da janela".
4. O aplicativo cria um campo para CADA concurso.
5. Digite a pontuação exata desejada para cada concurso.
6. Digite as dezenas ausentes.
7. O motor procura um jogo de 50 dezenas que reproduza a estrutura.

Exemplo:
2963=10
2964=16
2965=10
...
2971=20
2972=10

## Regras adicionais
- tenta colocar todas as ausentes; se não conseguir, maximiza a quantidade;
- mínimo 3 dezenas por linha 00-09 ... 90-99;
- barra de progresso, contador de trocas e ETA;
- auditoria concurso por concurso;
- justificativa das dezenas;
- PDF usa exatamente o mesmo jogo da tela.
